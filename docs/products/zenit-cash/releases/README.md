# Novidades do Zenit Cash

Esta pagina reune somente versoes que foram formalmente fechadas. Implementacoes
intermediarias podem ser publicadas sem criar uma nova versao; a numeracao avanca
quando um novo conjunto de mudancas e consolidado pelo responsavel pelo produto.

## Versoes

| Versao | Data | Destaque | Tag Git |
| --- | --- | --- | --- |
| [1.0.0](zenit-cash-1-0-0-release-notes.md) | 2026-09-18 | Planejamento e saude financeira pessoal | `zenit-cash-v1.0.0` |

## Como interpretar a numeracao

- o primeiro numero representa uma mudanca ampla ou incompativel;
- o segundo representa novos recursos compativeis;
- o terceiro representa correcoes e melhorias compativeis.

Os lancamentos anteriores a `1.0.0` fazem parte da base historica do produto e
nao receberam numeracao retroativa.
