# Organizar assuntos no Day

## Começar

O Day é um aplicativo para Windows e Android. Entre com sua conta do Day e aguarde a sincronização. Se ainda não tiver o aplicativo ou uma conta, consulte o [suporte](/contato).

## Criar um assunto

Um assunto pode ser algo que você executa ou que precisa acompanhar com outra pessoa.

1. Crie o assunto e escreva um título que você reconheça depois.
2. Registre o contexto e o próximo passo.
3. Se precisar, defina grupo, subgrupo e checklist.
4. Escolha a prioridade: **Baixa**, **Normal**, **Importante** ou **Urgente**. O padrão é Normal.
5. Defina prazo e retomada somente quando fizerem sentido e salve.

Informar um responsável não compartilha o assunto com essa pessoa. Concluir todos os itens do checklist também não conclui automaticamente o assunto.

## Prazo, retomada e meta de hoje

| Campo        | Pergunta que ajuda a responder                        |
| ------------ | ----------------------------------------------------- |
| Prazo        | Até quando o assunto precisa estar resolvido?         |
| Retomada     | Quando quero olhar para ele novamente?                |
| Meta de hoje | Quero iniciar, avançar, finalizar ou acompanhar hoje? |
| Prioridade   | Quanta atenção este assunto merece?                   |

**Não hoje** retira o assunto da intenção de trabalho imediato; não o conclui nem apaga o prazo. A prioridade não reordena automaticamente a lista.

## Acompanhar o progresso

Use **Hoje** para orientar a rotina e **Acompanhamentos** para consultar os assuntos abertos. Registre andamentos para manter o contexto. Conclua quando o assunto estiver resolvido; reabra quando precisar retomá-lo. Arquivar preserva o registro em **Arquivados**.

No Windows, fechar a janela mantém o aplicativo na bandeja. Para encerrar, use **Sair do aplicativo** no menu da bandeja.

## Trabalhar sem internet

As alterações ficam no dispositivo e são sincronizadas quando houver conexão, com o aplicativo em execução. Aguarde a indicação de sincronização antes de esperar que outro dispositivo ou o Hub veja a mudança.

Se o mesmo assunto mudar em dois dispositivos, compare as versões apresentadas. Não desinstale nem limpe os dados para resolver um conflito: isso pode apagar alterações ainda não sincronizadas.

## Lembretes e cópias

O sino no cabeçalho abre a gestão de lembretes. Você pode criar, editar, pausar, retomar e excluir uma regra, com ou sem vínculo a um assunto. Veja [como usar lembretes recorrentes](reminders-guide.md).

Em **Ajustes**, exporte uma cópia quando necessário. A restauração cria novos registros; não deve ser usada como uma sincronização entre dispositivos. Lembretes restaurados ficam pausados para revisão.

Para consultas por conversa, veja [como conectar o Day ao Hub](/docs/help/zenit-hub/getting-started).
