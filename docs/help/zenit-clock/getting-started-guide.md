# Registrar horas com o Clock

## Preparar o acesso

O Clock é um aplicativo para Windows que usa sua conta do Clockify. Consulte [disponibilidade e instalação](/contato), abra o aplicativo e configure a conexão com sua API key do Clockify.

A credencial fica no cofre do sistema operacional. Não envie a chave por mensagem nem a inclua em capturas de tela. Escolha o espaço de trabalho que contém os projetos que você usa.

## Fazer um lançamento

1. Selecione o projeto carregado do Clockify.
2. Escolha uma atividade cadastrada ou um cartão do Trello, se a integração estiver configurada.
3. Acrescente um complemento à descrição, se necessário.
4. Informe a data, o horário inicial e a duração no formato **HH:MM**.
5. Confira o horário final calculado.
6. Revise o resumo e confirme o envio.

O lançamento fica no Clockify. O Clock usa campos estruturados, sem interpretação de linguagem natural por IA.

## Consultar e corrigir

Ao escolher o projeto e a atividade, consulte os registros recentes e os totais apresentados. O histórico também considera descrições com complemento.

Um lançamento finalizado e não bloqueado pode ser carregado para revisão e atualizado no Clockify. A ação **Desfazer** permite excluir o último lançamento enviado pelo aplicativo; confira qual registro está selecionado antes de confirmar.

## Trello é opcional

Configure a chave e o token do Trello no aplicativo e associe um projeto do Clockify a um quadro e a uma coluna. O Clock consulta cartões abertos e usa o identificador e título na descrição enviada ao Clockify.

A integração é de leitura. Ela não move nem altera os cartões do Trello.

## Atalho e disponibilidade

Use **Ctrl + Shift + Espaço** para trazer a janela para frente. A versão descrita aqui é a de Windows. O Clock não faz parte das conexões de consulta do Hub pelo WhatsApp.
